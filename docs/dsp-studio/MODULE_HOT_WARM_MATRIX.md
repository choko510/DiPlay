The Native Dynamics and Dynamic EQ parameter helpers are wired through the existing bounded HOT mailbox; no parallel queue is used. `HOT`, `LOCAL_WARM`, `WARM`, and `DEFERRED` describe runtime plans, not UI optimism. ## Global rejection conditions

- Non-MEDIA roles never receive the full DSP update path.
- Track latency mismatch, PCM format change, renderer-owner change, stale generation, or invalid Native payload rejects the candidate.
- The Local Warm rollout flag defaults off. With it off, committed-track PEQ/Bass changes defer with a reason.
- Audio callbacks do not allocate or wait for preparation. Preparation, history catch-up, and resource retirement use control/reaper paths; the callback applies only bounded work.
- At `eecf550b1d52f4c5ddc5af292f558a743e5ade48`, Native regular tests, Shared unit tests, API 36.1 instrumentation (23/23), three Debug NDK ABIs, mobile/automotive Debug and Benchmark builds, JNI mapping, and `git diff --check` passed. Host ASan/UBSan could not link because MSYS2 lacks `libasan`/`libubsan`; the available emulator is API 36.1 rather than API 35. Target-device audio, A/V, p99, and acoustic claims remain `NOT_RUN`.
