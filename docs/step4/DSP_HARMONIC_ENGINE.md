# DSP-04 Harmonic Engine

The opt-in Harmonic Engine has a high-frequency exciter and a virtual-bass branch. Each branch uses a bounded even, odd, or mixed polynomial shaper between 2× Blackman-windowed FIR interpolation and decimation. The exciter branch also has a sample-rate-relative upper-band guard before shaping; it reduces nonlinear alias products near Nyquist without removing the high-frequency fundamental from the delayed dry signal. The FIR quality choices use 9, 17, or 33 taps and report 4, 8, or 16 input-frame latency; the dry path is delayed by the same fixed amount. The shaped nonlinear component is added to the delayed dry signal; it does not subtract the identity input. A DC blocker follows the even-harmonic paths.

Both branches default off. Exciter and bass amounts are capped at 0.5 each, Auto Headroom budgets the combined peak bound after level matching, level matching is enabled by default, and the existing final limiter remains last. Prepared FIR coefficients, fixed rings, and filter state are allocated before the render loop. Active changes wait for the next track generation.

Native tests sweep fundamental gain over 44.1/48 kHz, EVEN/ODD/MIXED modes, all FIR qualities, 1/8/12/15 kHz tones, and 0.001/0.05/0.45/0.9 peak levels with internal level matching disabled. Low-level gain must stay within 5% of dry. The alias checks include 13.5/15/17/18.5/19.5/20/20.4 kHz upper-band tones where below Nyquist and 6/12/18 kHz cutoff settings; the native unsanitized run on 2026-10-23 passed the folded second/third harmonic bound at 0.9 peak across the tested modes and FIR qualities. Additional tests cover quality latency, block-boundary invariance, and disabled-path parity. The main source tree contains no SoundRiser or Realizer stage; this implementation does not layer on a second instance of either.

No THD, sound-quality, or in-car benefit claim is made until target-speaker measurements and listening checks are recorded.
